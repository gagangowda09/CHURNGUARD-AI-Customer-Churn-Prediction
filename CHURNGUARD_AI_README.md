# CHURNGUARD AI — Customer Churn Prediction & Retention Intelligence System

## Files
- `CHURNGUARD_AI_Complete_Project.ipynb` — complete Google Colab/Jupyter notebook.
- `churn_guard_ai_model.joblib` — generated after running the notebook.
- `CHURNGUARD_AI_Project_Report.pdf` — generated automatically after running the notebook.

## How to Run
1. Open Google Colab.
2. Upload `CHURNGUARD_AI_Complete_Project.ipynb`.
3. Run all cells from top to bottom.
4. The notebook downloads the IBM Telco Customer Churn sample dataset if a local CSV is not uploaded.
5. At the end, download the generated PDF report and saved model.
6. Upload the notebook, report, model, and any required evidence to GitHub/submission form.

## Dataset
The notebook uses the IBM Telco Customer Churn sample dataset. The original IBM repository is archived but remains publicly accessible:
https://github.com/IBM/telco-customer-churn-on-icp4d

## Models
- Logistic Regression
- Random Forest
- Balanced Logistic Regression improvement

## Evaluation
- Accuracy

- ROC-AUC

- ROC curve

## Business Output
The notebook converts churn probability into LOW, MEDIUM and HIGH risk categories and gives a sample new-customer prediction.
